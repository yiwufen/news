# 金融语义标准

> 项目级规则以 `docs/SHARED_RULES.md` 为准；本文件保留 Claude 需要的专题规则摘录。

## 1. 事件类型 (risk_signal.type) 强制枚举

| 类型 | 说明 | 触发条件 |
|------|------|----------|
| `DEBT_DEFAULT` | 债务违约 | 包含逾期、展期失败、利息未付 |
| `EQUITY_PLEDGE` | 股权质押 | 关注质押比例 > 50% 的情况 |
| `LEGAL_SUIT` | 重大诉讼 | 标的额超过净资产 10% |
| `REAL_CONTROL_CHANGE` | 实控人变动 | 实控人变更或失联 |
| `RESTRUCTURING` | 资产重组 | 并购、分立、债务重组 |
| `POLICY_SANCTION` | 政策制裁 | 出口管制、行业处罚 |

## 2. 关系类型 (edges.relation) 强制枚举

| 关系 | 说明 | 必需属性 |
|------|------|----------|
| `INVESTS` | 股权投资 | `percent` (持股比例) |
| `GUARANTEES` | 担保 | `amount` (担保金额) |
| `DEBTOR_OF` | 债权债务 | `amount` (债务金额) |
| `ACTUAL_CONTROL` | 实际控制 | 无 |
| `OWNS` | 资产所有权 | `percent` (持股比例) |
| `ISSUES` | 发行产品 | 无 |

## 3. 风险传导权重 (Weight)

| 关系类型 | 权重 | 说明 |
|----------|------|------|
| 控股关系 | 0.9 | 直接联动，风险高度相关 |
| 关联担保 | 0.8 | 代偿风险，需重点关注 |
| 业务依赖 | 0.3 | 订单风险，影响相对间接 |

## 4. 风险等级 (risk_signal.level) 定义

| 等级 | 分值范围 | 处理优先级 |
|------|----------|------------|
| `CRITICAL` | >= 0.8 | 立即预警，人工介入 |
| `HIGH` | 0.6 - 0.8 | 当日处理，持续监控 |
| `MEDIUM` | 0.4 - 0.6 | 周报汇总，定期复查 |
| `LOW` | < 0.4 | 归档记录，作为背景信息 |

## 5. 实体类型 (nodes.type) 定义

| 类型 | 说明 | 示例 |
|------|------|------|
| `COMPANY` | 公司实体 | "阿里巴巴集团" |
| `PERSON` | 自然人 | "马云" |
| `ASSET` | 资产 | "某地块使用权" |
| `FINANCIAL_PRODUCT` | 金融产品 | "XX信托计划" |
